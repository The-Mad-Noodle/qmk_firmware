# Noodle Pad v.2 Keypad with Encoder

![NoodlePadv2 Main](https://static.wixstatic.com/media/59d0ff_b9beb2274b75415abea305779dcbaf02~mv2.png)
![NoodlePadv2 RGB](https://static.wixstatic.com/media/59d0ff_41b148fb0b414fe3a3c1a5dc3b745404~mv2.png)

The NoodlePad v.2 by The Mad Noodle Prototypes is a custom 3x3 mechanical keypad with an encoder knob and full RGB Underglow.

* Keyboard Maintainer: [The Mad Noodle Prototypes](https://github.com/The-Mad-Noodle)
* Hardware Supported: NoodlePad v2 PCB, ATmega32U4
* Hardware Availability: [MadNoodlePrototypes.com](https://www.madnoodleprototypes.com/shop)

Make example for this keyboard (after setting up your build environment):

    make themadnoodle/noodlepad/v2:default

See the [build environment setup](https://docs.qmk.fm/#/getting_started_build_tools) and the [make instructions](https://docs.qmk.fm/#/getting_started_make_guide) for more information.
